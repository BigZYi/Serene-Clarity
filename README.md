# ☀️「心晴」—— 桌面情绪管理助手

基于人脸表情识别的 AI 情绪管理助手：读懂你的表情，结合天气与时间，在你情绪低落时送上温暖的一句话。

## 项目方案

---

## 一、项目背景

据统计，中国高校大学生中约 20%~30% 存在不同程度的心理困扰，其中**想家、焦虑、情绪低落**是最常见的问题。然而，多数学生不会主动走进心理咨询室——他们更习惯于对着手机屏幕发呆，在宿舍里独自消化情绪。

**核心洞察**：当一个人面对摄像头时，如果 AI 能「读懂」表情，在合适的时刻说一句温暖的话——这比任何问卷调查都更及时、更有温度。

---

## 二、问题定义

| 痛点 | 现状 |
|------|------|
| 🕐 时效性差 | 心理咨询需要预约，情绪发生时无人回应 |
| 😶 主动性低 | 学生不愿主动开口求助 |
| 🏥 资源有限 | 高校心理咨询师配比严重不足 |
| 🌧 环境因素 | 天气、季节变化影响情绪却常被忽略 |

**我们要解决的是**：在情绪发生的当下，用最低门槛的方式给予及时、温暖的心理支持。

---

## 三、技术方案

### 3.1 整体流程

```
摄像头 → MediaPipe 表情识别 → 心理状态分类 → 天气+时间 → DeepSeek LLM → 文字/语音输出
```

### 3.2 核心模块

| 模块 | 技术 | 说明 |
|------|------|------|
| 🎭 **表情识别** | MediaPipe Face Landmarker | 478 点面部网格 + 52 个 blendshape 系数 → 7 种表情 |
| 🧠 **心理分析** | 规则引擎 + 滑动窗口 | 30 帧情绪累积 → 4 类心理状态（开心/低落/焦虑/平静） |
| 🌤 **环境感知** | uapis.cn 天气 API + 时间感知 | 每日缓存，天气/时段融入 LLM 上下文 |
| 🤖 **智能疏导** | DeepSeek V4 Flash | 大学生专属提示词 + 本地规则降级 |
| 🔊 **语音播报** | 华为云 VCS 语音合成 | 可选，将疏导文案播报出来 |
| 🌐 **交互界面** | Gradio 6.x | 静默守护 + 定时周期分析 + 网页端 |

## 五、核心功能

| 功能 | 描述 |
|------|------|
| 🔇 静默守护 | 摄像头持续分析，无需用户操作，摄像头默认折叠 |
| ⏱ 定时周期 | 每 30s 汇总情绪，调用 LLM 生成疏导 |
| 📸 拍立得模式 | 每 5 秒分析一帧，非连续流式，降低压迫感 |
| 🌤 天气联动 | 降温提醒加衣，阴雨天共情低落 |
| 🕐 时间感知 | 深夜温柔、白天精神，语气随时段变化 |
| 💬 主动对话 | 输入文字后可点击「获取疏导」即时触发 |
| 🔊 语音播报 | 可选，疏导文案自动合成语音（带防重播守卫） |
| ⏸ 暂停守护 | 用户可随时暂停/恢复，尊重"不想被关心"的时刻 |

| 语言 | Python 3.11 |

---

## 七、创新点

1. **静默守护交互范式**：摄像头折叠隐藏，用户零操作，隐私优先
2. **拍立得分析模式**：定时取帧替代连续流式，更省资源更安心
3. **多模态上下文融合**：表情 + 心理 + 天气 + 时间共同塑造疏导内容
4. **本地降级兜底**：API 不可用时自动切换本地规则，系统不中断
5. **模块化设计**：表情/心理/LLM/语音完全解耦，可独立替换升级
